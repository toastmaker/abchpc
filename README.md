- HPC vocabulary, CPU, memory architecture, cache, NUMA, threads vs processes
- Chimera cluster
- Modules
- Compiling
- SLURM (submitting, monitoring, cancelling jobs)
- Job arrays
- Checkpointing
- Containers
- Use of MCP

### L2 - openMP, MPI
### L3 - GPU, Python
### L4 - profiling & optimisation
